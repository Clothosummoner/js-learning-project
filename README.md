# Pokémon JavaScript Lernprojekt

Dieses Projekt habe ich erstellt, um grundlegende JavaScript-Konzepte zu üben.

## Funktionen
- Pokémon anzeigen
- Alle Pokémon anzeigen
- Nach Typ filtern
- Attacken hinzufügen
- Attacken entfernen
- Prüfen, ob ein Pokémon existiert
- Neues Pokémon hinzufügen

## Lernziele
- Arbeiten mit Objekten und Arrays
- Funktionen schreiben
- Daten manipulieren
- Logik und Bedingungen umsetzen

Dieses Projekt dient ausschließlich zu Lernzwecken.
