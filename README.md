# Pokémon JavaScript Lernprojekt

> **Hinweis:** Dies war mein erstes JavaScript-Lernprojekt und wird nicht mehr weiterentwickelt.
> Weil ich ein eigenes Projekt ohne geschützte Namen und Marken aufbauen wollte, lerne ich jetzt mit
> [ResourceFoundry](https://github.com/Clothosummoner/ResourceFoundry) weiter – einem eigenen Browser-Spiel.

Dieses Projekt habe ich erstellt, um grundlegende JavaScript-Konzepte zu üben.

## Funktionen

- Pokémon anzeigen
- Alle Pokémon anzeigen
- Nach Typ filtern
- Attacken hinzufügen und entfernen
- Prüfen, ob ein Pokémon existiert
- Neues Pokémon hinzufügen

## Lernziele

- Arbeiten mit Objekten und Arrays
- Funktionen schreiben
- Daten manipulieren
- Logik und Bedingungen umsetzen

Inoffizielles, nicht-kommerzielles Lernprojekt. Pokémon ist eine Marke von Nintendo, Creatures Inc. und GAME FREAK inc.
